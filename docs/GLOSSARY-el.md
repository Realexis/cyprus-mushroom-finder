# Greek glossary for Shroomy (collected 19 Nov 2026)

**What this is.** The Greek words used in the Greek version of the site, and where each one comes from.
Real asked that the Greek stay as close as possible to the official sources the project already used.

**Not checked by a native speaker.** Every Greek sentence on the site was written by an AI from these terms.

**How to read "Source".**

- A tag (FD-M, LAW ...) = the Greek word was read on that page, as printed there.
- **Own translation** = no source gives a Greek term. The word is ours.
- **No Greek name in a source** = the site keeps the scientific (Latin) name.

Some of the sources say that a mushroom can be eaten. The site never repeats that, in any language.

## 6. Gaps

- **The Greek leaflet is not online.** Its names came from Real on 14 Nov 2026. KYKPEE follows the leaflet species by species, so it was used to cross-check.
- **Nature reserve names on the map** (Kryos Potamos, Chionistra, Tripylos - Mavroi Kremmoi, Livadhi tou Pasha, Pikromiloudhi, Madari, Drys tis Lanias): no official Greek list of these seven names was found. They stay in English letters, as in the data file.
- **Units** stay as international symbols (m, km, mm, °C). Decimal commas are Greek ("7,5").
- **The sources disagree in places.** Leaf litter has three words. The site uses the newest official one, φυλλάδα.
